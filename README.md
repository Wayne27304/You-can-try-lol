# You-can-try-lol

這是一個基於 Python 的音訊視覺化程式，能夠讓你的螢幕背景隨著電腦播放的音樂節奏進行平滑的呼吸變色效果。

## 🛠 功能特色
* **自動同步**：透過系統音訊通道即時偵測節奏。
* **恩對**：我也不知道我要做這個要幹甚麼

## 🚀 快速開始
### (在Releases下載.exe)

### 1. 安裝依賴
在終端機執行：
```bash
pip install -r requirements.txt
```
